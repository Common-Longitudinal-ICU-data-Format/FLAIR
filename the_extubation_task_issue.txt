p is always P(extubation failure). The model outputs one number: "chance this patient needs the tube back within 24h." That is true before this change and after it. Nothing about the model, the training, or the predictions file changes.

1−p is P(successful extubation). Your model never computes it. The report computes it, in one place, for one purpose: drawing the decision curve. That's it.

So when I said "flip the frame, not the score" — the score stays p forever. 1−p exists only inside report/_basis.py.

Why not just have the model output 1−p? Two reasons. AUROC literally cannot tell the difference (it's rank-based, flipping is a no-op), so you'd gain nothing. But AUPRC very much can: failure is 5.4% of cases, success is 94.6%. Score "success" and you'd report an AUPRC around 0.95 that means nothing — a model predicting "everyone succeeds" would get it. Keeping the rare bad thing as the positive class is what makes that number honest.

Direction = which side of the line triggers the action

Threshold t = 0.10.

┌───────────────────┬───────────────────────────────────────┬────────────────────────────────┐
│                   │      above (your other 3 tasks)       │       below (this task)        │
├───────────────────┼───────────────────────────────────────┼────────────────────────────────┤
│ Rule              │ act when p ≥ t                        │ act when p < t                 │
├───────────────────┼───────────────────────────────────────┼────────────────────────────────┤
│ Example           │ mortality ≥ 0.95 → palliative consult │ failure risk < 0.10 → extubate │
├───────────────────┼───────────────────────────────────────┼────────────────────────────────┤
│ Who gets acted on │ the high-risk minority                │ the low-risk majority          │
└───────────────────┴───────────────────────────────────────┴────────────────────────────────┘

That's the whole meaning of "direction." It's one boolean: does the action fire on the high side or the low side of the threshold.

For this task, low risk → pull the tube. High risk → leave it in. So below.
