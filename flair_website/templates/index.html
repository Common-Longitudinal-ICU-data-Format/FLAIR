What is FLAIR?

Three coupled artifacts: a data layer, a task layer, and a federated protocol.

CLIF-anchored datasets

CLIF is a critical-care minimum dataset that harmonizes ICU EHR content into a small set of relational tables with standardized vocabularies (mCIDE). The same coded vocabulary at every site means FLAIR measures genuine cross-site generalizability.

Learn more →

Curated, extensible tasks

Five binary tasks span outcome, deterioration, and intervention targets. Any researcher can add a new task as a single Python file — a META dict plus a build() function — via GitHub pull request.

Learn more →

Federated, private reporting

No patient rows leave a site. The library emits TRIPOD+AI metrics, subgroup fairness gaps, and calibration curves as aggregate JSON, with HIPAA cell suppression applied site by site.
