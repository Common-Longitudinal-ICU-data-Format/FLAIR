FLAIR 101

A practical, top-to-bottom guide for an external user — a method developer, a site data steward, or someone authoring a new benchmark task.

FLAIR is a federated ICU benchmark: the code travels to the data, and only aggregate JSON ever leaves a site. You develop and self-evaluate against the public MIMIC-CLIF dataset; the same code later runs unmodified behind a hospital's firewall.

What FLAIR is

The model-to-data loop. A model is built and validated against public MIMIC-CLIF, reviewed, then shipped to each consortium site. Each site runs it against its own CLIF tables and returns a small bundle of aggregate-only JSON. Patient-level rows never move.

Two packages:

packageCLIwhat it gives you
flair-benchmarkflairthe library: task catalog, cohort builder, feature extractors, report builder
flair-baselineflair-baselinean optional reference XGBoost count-feature model

Privacy guarantees baked into the library:

  • No patient rows leave a site — outputs are JSON aggregates only.
  • Cell-count suppression: any count < 10 is written as "<10" in table1.json.
  • Demographic subgroups with n < 10 are dropped entirely from fairness.json.

Install & first config

The PyPI release is coming soon (v1):

pip install flair-benchmark          # core library + `flair` CLI
pip install "flair-benchmark[viz]"   # add matplotlib for local sanity-check PNGs

Scaffold the two config files from the CLI:

flair init-config --out .
# writes clif_config.json + feature_config.yaml (pass --force to overwrite)

clif_config.json tells FLAIR where your CLIF data lives and how to read it:

fieldmeaning
site"mimic" triggers the deterministic 70/30 split; any other name is a label/prefix
data_directoryroot folder of your CLIF parquet/CSV files
filetype"parquet" or "csv"
timezonesite-local tz, e.g. "US/Eastern" — stripped to local wall-clock
stitch_time_interval_hoursgap (default 6) below which hospitalizations merge into one stitched hospitalization
cache_directorywhere intermediate artifacts are cached

End-to-end quickstart

# 0. install + scaffold
pip install "flair-benchmark[viz]"
flair init-config --out .
#   …edit clif_config.json: set data_directory + timezone…

# 1. see what tasks exist
flair list-tasks

# 2. build a cohort  ->  cohort.parquet + cohort.table1.json
flair load-task task1_icu_daily_mortality \
  --clif-config clif_config.json --out cohort.parquet

# 3. engineer features  ->  ELF-long event parquet
flair fe-wide --feature-config feature_config.yaml \
  --task cohort.parquet --out features.parquet

# 4. …train YOUR model -> preds.parquet (hospitalization_id, split, label, y_prob)…

# 5. build the report bundle  (continuous task -> pick peak or landmark)
flair build-report preds.parquet --task task1_icu_daily_mortality \
  --cohort cohort.parquet --mode landmark --out ./report/
