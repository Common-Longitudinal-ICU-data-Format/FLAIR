\noindent\textbf{Data and Code Availability.} Source code, task
definitions, and report-generation library are released under Apache
2.0 at \texttt{github.com/clif-consortium/FLAIR}. MIMIC-CLIF is
distributed via PhysioNet; consortium data are accessible only by
running submitted code at each site through the FLAIR portal.
Baseline model weights are deposited on Zenodo (\todo{DOI}); the
CLIF-WorkBench Singularity image is published on GHCR (\todo{tag}).

\noindent\textbf{IRB.} Each consortium site obtained independent
institutional review board approval; central protocol coordination is
provided by the University of Chicago.
