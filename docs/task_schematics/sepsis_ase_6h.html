Task T4 · continuous · one-per-window

Sepsis Prediction with CDC ASE Time-Zero

Predict whether a hospitalized patient will meet the CDC Adult Sepsis Event (ASE) surveillance definition within the next 6 hours. Time-zero (t_zero) is fixed at ASE onset, predictions start at the first recorded vital sign, and predictions stop strictly before t_zero to avoid the label-leakage failure mode documented by Kamran et al. [Kamran 2024].

Audit · code diverged from original spec The original LaTeX schematic anchored t_zero on the first qualifying IV antibiotic. The shipped code (task4_sepsis_abx_6h.py, commit “update the ASE as sepsis task”) re-anchors t_zero on CDC ASE onset via clifpy.utils.ase.compute_ase. This page documents the code. Concrete differences:
  • t_zero = min(ase_onset_w_lactate_dttm | sepsis==1), not first antibiotic.
  • Label column is label_sepsis_6h (not label_sepsis_abx_6h); positive class ase_onset_within_6h; display “Sepsis (CDC ASE onset) within 6h”.
  • The microbiology_culture table (blood cultures) is required — compute_ase raises without it. The antibiotic-anchored label is retained only as a documented fallback.
  • pred_stop uses a true earliest-of (min_horizontal), not min(t_zero, t_end).
  • Runs on the stitched-encounter grain; t_zero / first-vital folded as min over members.

Introduction

Sepsis prediction is the most-studied AI use case in inpatient EHR research, yet there is no consensus on when a model's prediction should be considered correct [Sepsis-3], [Rhee 2019]. The choice of time-zero changes both the label and the cohort, and Kamran et al. showed the Epic Sepsis Model's AUROC drops from 0.62 to 0.47 when predictions made after a clinician's first sepsis-treatment order are excluded. This is the label-leakage problem: when the gold label is itself an administrative event, any prediction made after that event trivially correlates with the outcome it is supposed to forecast.

FLAIR's other tasks (mortality, LTACH, extubation, readmission) use events that are either involuntary (death) or occur at a clean state transition (ICU discharge). Sepsis is different: the label folds in clinician/diagnostic actions. The task therefore must (i) pick an unambiguous anchor and (ii) censor predictions made at or after that anchor. FLAIR anchors on CDC ASE onset — the earliest contributing ASE criterion — and terminates the prediction window strictly before it.

Implications for FLAIR. The Seymour-paired definition dominates the AI-sepsis literature but is sensitive to culture-order timing, which itself reflects clinician suspicion. No two studies use the same cohort entry rule (ICU-only vs hospital-wide vs ED-onset), producing materially different prevalence. Kamran 2024 is the first to quantify the cost of label leakage by re-evaluating a deployed model under a stricter “before clinician action” rule. FLAIR adopts the CDC ASE arm of their composite label and applies the pre-treatment-indicator gate as a structural property of the training label itself.

FLAIR operational definition

Anchors and windows

Let \(H_i\) denote a stitched encounter with admission time \(t^{\text{adm}}_i\) and discharge or death time \(t^{\text{end}}_i\). Anchors are computed per member hospitalization and folded to the encounter (min over members).

Time-zero (t_zero) — CDC ASE onset
\[ t_{\text{zero}}^i = \min\{\,\texttt{ase\_onset\_w\_lactate\_dttm} \mid \texttt{sepsis}=1\,\} \] computed by compute_ase (apply_rit=True, include_lactate=True). ASE onset is the earliest contributing criterion — LEAST(blood_culture, first_qualifying_antibiotic_day, vasopressor, IMV, AKI, hyperbilirubinemia, thrombocytopenia, lactate) — the conservative, leak-safe anchor. Encounters that never meet ASE have \(t_{\text{zero}}^i = \texttt{null}\,(+\infty)\).
Prediction-window start (pred_start)
\[ \text{pred\_start}_i = \max\!\bigl(\min\{t \mid \text{vitals}(i,t)\neq\emptyset\},\ t^{\text{adm}}_i + 1\text{h}\bigr) \] — the first recorded vital sign, floored at \(t^{\text{adm}}_i + 1\text{h}\) to guarantee a non-degenerate window when vitals are taken immediately at admission.
Prediction-window stop (pred_stop)
\[ \text{pred\_stop}_i = \min\!\bigl(\texttt{coalesce}(t_{\text{zero}}^i, t^{\text{disch}}_i),\ t^{\text{disch}}_i,\ t^{\text{death}}_i\bigr) \] a true earliest-of (min_horizontal), not coalesce(death, discharge): death_dttm is patient-level, so a post-discharge death must not push the window past discharge. The interval \([\text{pred\_start}_i, \text{pred\_stop}_i)\) is closed-open; \(t_{\text{zero}}^i\) is not a decision point.
Decision-point grid
Hourly: \(D_i = \{\text{pred\_start}_i + k\cdot 1\text{h} : k\in\mathbb{Z}_{\ge 0},\ \text{pred\_start}_i + k\cdot 1\text{h} < \text{pred\_stop}_i\}\).
Label (label_sepsis_6h)
For \(d \in D_i\): \[ y_i(d) = \mathbb{1}\!\left[ t_{\text{zero}}^i \neq \texttt{null} \ \wedge\ d < t_{\text{zero}}^i \le d + 6\text{h} \right]. \] Encounters with no ASE onset contribute all-negative rows over the entire \([\text{pred\_start}_i, t^{\text{end}}_i)\).

Cohort (hospital-wide, Kamran 2024)

  • Age at admission \(\ge 18\) with valid admission_dttm and discharge_dttm.
  • Exclude any ADT stay on a psychiatric or rehabilitation unit (EXCLUDE_LOCATION_CATEGORIES = ["psychiatric", "rehabilitation"]; encounter-grain anti-join).
  • Exclude already-septic-at-entry: \(t_{\text{zero}}^i \le \text{pred\_start}_i\).
  • Exclude encounters with no vital-sign measurements (pred_start undefined).
Data requirement compute_ase needs the CLIF microbiology_culture table (blood cultures, fluid_category == 'blood_buffy') to establish ASE Component A. The task raises FileNotFoundError if it is absent — exports lacking it cannot produce a usable label.

CLIF tables and categories used

Task T4 directly loads four tables and delegates ASE computation to compute_ase, which pulls the remaining surface. Note the structural asymmetry with T1/T2/T3/T5: T4 is the only task whose ADT filter excludes by category rather than restricting to "icu".

The _w_lactate ASE arm includes lactate ≥ 2.0 mmol/L as an organ-dysfunction criterion, bringing the CDC ASE definition closer to the CMS SEP-1 arm Kamran 2024 also uses.

Sensitivity / fallback arms (documentation only)

  • Antibiotic-anchored fallback. If microbiology_culture is unavailable, revert t_zero to the first qualifying systemic IV antibiotic (med_group="cms_sepsis_qualifying_antibiotics" ∧ med_route_category="iv") — the original schematic's definition.
  • ICU-only arm. Restrict to encounters with ≥1 ICU ADT record; \(\text{pred\_start}_i = \max(\text{first\_icu\_start}_i + 1\text{h},\ \text{first vital})\).
  • Seymour-paired arm. Require a blood culture in \((t_{\text{zero}}-72\text{h},\ t_{\text{zero}}+24\text{h})\) for the anchor to qualify.
  • Sepsis-3 label arm. Replace ASE-as-label with \(\Delta\text{SOFA}\ge 2\) within ±48h of \(t_{\text{susp}}\) (PhysioNet 2019 rule) for cross-comparison.

Build pipeline. Solid arrows: main flow. Dashed red arrows: exclusions. The diamond enforces the label-leakage gate: any encounter whose ASE onset precedes its first vital sign is dropped, since no decision point in that stay can produce a recognition-free prediction.

  1. Load CLIF tables; build the hospital-wide adult cohort; exclude psych/rehab ADT (encounter-grain anti-join).
  2. Collapse to stitched-encounter grain (demographics + member admission/discharge).
  3. Compute first_vital_dttm per member, fold to encounter (min), then pred_start = max(first_vital, admission + 1h).
  4. Run compute_ase; keep septic episodes; \(t_{\text{zero}}\) = min ASE onset per encounter.
  5. Apply the leakage gate: keep iff \(t_{\text{zero}}\) is null OR \(t_{\text{zero}} > \text{pred\_start}\).
  6. Compute pred_stop = min_horizontal(coalesce(t_zero, discharge), discharge, death).
  7. Explode the hourly grid \([\text{pred\_start}, \text{pred\_stop})\) (pl.datetime_ranges, closed-open).
  8. Assign \(y_i(d) = \mathbb{1}[t_{\text{zero}} \in (d, d+6\text{h}]]\).
  9. Assign window_start = d − 24h, window_end = d (fixed 24h lookback).
  10. Apply temporal split (keyed on prediction_dttm); select OUTPUT_COLS; persist as parquet.

Design choices and rationale

Why CDC ASE onset as the anchor

The CDC ASE arm of Kamran 2024's composite label is reproducible from structured CLIF data via clifpy's reference compute_ase. Anchoring on the earliest contributing ASE criterion (LEAST over component timestamps) is the conservative, leak-safe choice: because ASE onset folds in treatment/diagnostic actions (blood culture, qualifying antibiotics, vasopressors), any prediction at or after it would trivially correlate with the outcome — so the window terminates strictly before \(t_{\text{zero}}\).

Why strictly pred_stop ≤ t_zero with no Δ-gate

Kamran 2024 introduce no fixed buffer; they restrict analysis to “predictions occurring before sepsis criteria were met and before the first indicator of treatment.” FLAIR follows that parsimonious rule: the onset timestamp itself is the cutoff.

Why hospital-wide (not ICU-only)

Hospital-wide matches Kamran 2024's cohort and captures the operationally important ward-onset sepsis cases, where prediction lead time has the most clinical value. The ICU-only variant is preserved as a sensitivity arm for comparability with DeepAISE and InSight.

Why hourly grid

Matches the FLAIR convention and the PhysioNet/CinC 2019 standard. ESM's native 20-minute cadence is finer than necessary for benchmarking and would inflate row counts ~3× without adding label resolution.

Prevalence implications

Hospital-wide hourly grids produce highly imbalanced labels: a 7-day stay with one onset event produces ≤6 positive rows out of ~160. Reporting AUPRC alongside AUROC is mandatory.

Out of scope

  • Choice of input features and feature engineering.
  • Curated antibiotic drug list and med_category mapping (relevant to the antibiotic-anchored fallback).
  • Sensitivity-arm output schemas.
