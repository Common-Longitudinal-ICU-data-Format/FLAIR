Task Schematics

Self-contained design documents for the four FLAIR prediction tasks. Each page specifies the cohort, anchors, prediction window, label rule, and censoring logic, with a build-pipeline flowchart. These HTML pages track the implementation in flair_benchmark/tasks/<name>.py; where code and the original LaTeX spec drifted, the HTML follows the code and flags the change.

TASK · continuous

ICU Daily In-Hospital Mortality (07:00)

Each morning of the first ICU stay, will this hospitalization end in death or hospice? Unconditional adult-ICU cohort.

 TASK · continuous

ICU Daily LTACH Discharge (07:00)

Same cohort and grid as ICU Daily Mortality; predicts transfer to a Long-Term Acute Care Hospital. The two daily tasks are not a partition.

 TASK · one-per-stay

Extubation Failure within 24h

30 min before the first confirmed extubation, will the patient be reintubated within 24h? Consensus-window IMV episode detector.

 TASK · one-per-stay

Unplanned ICU Readmission

At first-ICU discharge, will the patient return to the ICU later in the same hospitalization through an unplanned path? ADT-only.

Conventions shared by every task

Stitched-encounter grain

Code note All four tasks operate on stitched encounters, not raw hospitalizations. Member hospitalizations that are contiguous (gap ≤ 6h, fixed in constants.STITCH_TIME_INTERVAL_HOURS) are folded to a single hospitalization_join_id via the encounter index. Anchors are taken as a min/max over the encounter's members (e.g. admission = min, discharge = max, t_zero / first-vital = min over members), and the output is keyed by encounter so a stitched re-admission becomes one series, not two. The original schematics were written per-hospitalization (H_i); read every H_i below as the stitched encounter.

Train/test split & output

Each task ends with a train/test split (flair_benchmark.cohort.stitch.assign_split, keyed on prediction_dttm): temporal (oldest 75% train, newest 25% test, or explicit --train-end/--test-start dates; deterministic random 75/25 for site="mimic" when no dates are given), and persists a parquet with the label column, split, and demographics. Datetimes are naive wall-clock-local per cfg["timezone"]; literal hours (e.g. 07:00) are local hospital time. Tasks are heavily class-imbalanced, so AUPRC is reported alongside AUROC.
