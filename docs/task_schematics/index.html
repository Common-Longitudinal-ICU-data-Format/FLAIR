Task Schematics

Self-contained design documents for the five FLAIR prediction tasks. Each page specifies the cohort, anchors, prediction window, label rule, and censoring logic, with a build-pipeline flowchart. These HTML pages track the implementation in flair_benchmark/tasks/task<N>_*.py; where code and the original LaTeX spec drifted, the HTML follows the code and flags the change.

TASK T1 · continuous

ICU Daily In-Hospital Mortality (07:00)

Each morning of the first ICU stay, will this hospitalization end in death or hospice? Unconditional adult-ICU cohort.

 TASK T2 · continuous

ICU Daily LTACH Discharge (07:00)

Same cohort and grid as T1; predicts transfer to a Long-Term Acute Care Hospital. T1 and T2 are not a partition.

 TASK T3 · one-per-stay

Extubation Failure within 24h

At the first confirmed extubation, will the patient die or be reintubated within 24h? Consensus-window IMV episode detector.

 TASK T4 · continuous

Sepsis (CDC ASE onset) within 6h

Hourly hospital-wide prediction of CDC Adult Sepsis Event onset within 6h, censored before t_zero to avoid label leakage.

 TASK T5 · one-per-stay

Unplanned ICU Readmission

At first-ICU discharge, will the patient return to the ICU later in the same hospitalization through an unplanned path? ADT-only.

Conventions shared by every task

Stitched-encounter grain

Code note All five tasks operate on stitched encounters, not raw hospitalizations. Member hospitalizations that are contiguous (gap ≤ stitch_time_interval_hours, default 6h) are folded to a single hospitalization_join_id via the encounter index. Anchors are taken as a min/max over the encounter's members (e.g. admission = min, discharge = max, t_zero / first-vital = min over members), and the output is keyed by encounter so a stitched re-admission becomes one series, not two. The original schematics were written per-hospitalization (H_i); read every H_i below as the stitched encounter.

Temporal split & output

Each task ends with a temporal train/test split (flair_benchmark._split.assign_split, keyed on prediction_dttm) and persists a parquet with the label column, split, and demographics. Datetimes are naive wall-clock-local per cfg["timezone"]; literal hours (e.g. 07:00) are local hospital time. Tasks are heavily class-imbalanced, so AUPRC is reported alongside AUROC.
