02 · Components

Three CLI primitives.

FLAIR is a thin polars-on-clifpy layer with three commands: build a cohort, score predictions, summarize the site. Everything else (your features, your model) is yours.

load-task Cohort parquet build-report 4-JSON bundle extract-metadataSite summary JSON list-tasks Auto-discovered

1 · Task generation

One polars file per task under flair_benchmark/tasks/. Each exposes a META dict + a build() function. flair load-task materializes the cohort parquet — the contract every model trains against.

flair load-task task6_hospital_mortality \
    --clif-config clif_config.json \
    --train-end 2022-12-31 \
    --test-start 2023-01-01 \
    --out cohort.parquet
# omit --train-end / --test-start on MIMIC → 70/30 temporal split fallback

2 · Build report

Train your model. Write back y_pred / y_prob alongside the cohort. Run build-report — four standardized JSONs land in --out, every cell HIPAA-suppressed.

flair build-report preds.parquet \
    --task task6_hospital_mortality \
    --out ./report/
table1.json
Cohort × split × label
n < 10 → "<10"
tripod_ai.json
AUROC, AUPRC, calibration, Brier
TRIPOD-AI auto-populated
fairness.json
Per-subgroup metrics + parity gaps
Subgroups with n < 10 dropped
curves.json
ROC / PR / calibration points
Downsampled — central dashboard renders

Every JSON carries audit metadata: task_script_sha256, flair_version, generated_at. The aggregator can verify two sites ran byte-identical code.

3 · Longitudinal summary

Run once per site, independent of any submission. Emits one JSON per (site, task) for the public leaderboard — prevalence, demographics, first-24h SOFA, Charlson + Elixhauser at admission, and yearly counts so the dashboard can show site-drift over time.

flair extract-metadata \
    --clif-config clif_config.json \
    --out ./meta/
# → meta/task6_hospital_mortality.json (one file per task)

Longitudinal = yearly bucket. Lets the leaderboard show drift in case-mix, prevalence, and severity over years — a federated benchmark needs to know its denominator is moving.

Auto-discovery

Drop a new .py under flair_benchmark/tasks/ exposing META + build(). flair list-tasks picks it up — no registry, no router. That is the entire add-a-task contract.

$ flair list-tasks
task1_discharged_home          outcome        episode         one-per-stay              binary
task2_discharged_ltach         outcome        episode         one-per-stay              binary
...
