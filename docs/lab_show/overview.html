01 · Overview

An evaluation ecosystem for ICU CDSS digital twins.

FLAIR is more than a benchmark. It is an open evaluation ecosystem for ICU AI / ML / CDSS — the place where new clinical decision-support tools come to declare their strengths and weaknesses against the question every critical-care team eventually asks: what does good actually look like?

By evaluating models on real, private ICU data across 17+ CLIF sites — not on a single development cohort — FLAIR generates the high-quality, multi-site evidence that turns a proof-of-concept into a candidate ready for the bedside. The benchmark is the entry test; the ecosystem is what surrounds it.

Beyond a benchmark — an evaluation ecosystem

Generalizability, not performance
Multi-site evaluation by default.
Single-site AUROCs do not survive transport. FLAIR measures how a model travels.
High-quality evidence
Cross-site reports, not anecdotes.
TRIPOD-AI + FairCareAI bundles per site, aggregated into a public, reproducible scoreboard.
Strengths and weaknesses
The scoreboard forces both.
Every submission surfaces where it fails — by site, subgroup, year — before it can be considered for bedside use.
Open by construction
Tasks · code · reproducibility.
Any researcher can PR a new task against MIMIC-CLIF. Every evaluation is rerunnable from the audit-stamped JSON trail.

The data layer

CLIF
Common Longitudinal ICU Format.
Shared schema across 17+ academic medical centers, 2000+ ICU beds.
mCIDE
Minimal Common ICU Data Elements.
Harmonized clinical vocabulary — vitals, labs, meds, devices, assessments.
clifpy
Python loader + wide-dataset builder.
Same code runs against MIMIC-CLIF and consortium sites.
FLAIR
Benchmark CLI on top of clifpy.
Task cohorts · standardized reports · longitudinal summaries.

MIMIC-CLIF is the on-ramp

Write and validate your task script against MIMIC-CLIF. When it works there, the same code runs at every consortium site — no schema differences, no per-site forks.

Open-bench premise

Tasks live in flair_benchmark/tasks/ — one polars file per task, auto-discovered. If your task is not in the catalog, write it against MIMIC-CLIF and open a PR. The contract is one META dict and one build() function. No registry, no router.
